# 🚀 Learning TestNG Testing Framework

Welcome to the **Learning TestNG** repository! 📚 This repository is your guide to understanding and mastering **TestNG**, one of the most powerful testing frameworks in Java. It contains well-organized Java examples and XML configurations to help you grasp essential TestNG concepts and features. 🧪✨

---

## 📁 Repository Structure

### 📂 **Directories:**
- **DataProvider** 📦  
  Demonstrates the use of the `@DataProvider` annotation for parameterized tests.

- **listener** 🔊  
  Examples of implementing TestNG listeners at the XML configuration level.

- **parallel** 🏃‍♂️💨  
  Learn how to perform parallel execution of test methods and classes.  

- **parameter** 📊  
  Explores the use of parameters in TestNG tests.

---

### 📝 **Java Files:**
- **AnnotationsHierarchyExample.java** 🏷️  
  Examples illustrating the hierarchy and order of TestNG annotations.  

- **DependsOnTest.java** 🔗  
  Shows how to use `dependsOnMethods` for dependent tests.

- **GroupTest.java** 👥  
  Learn about grouping tests and running specific groups using `@Test(groups = "groupName")`.  

- **HardAssertionTest.java** & **SoftAssertionTest.java** ⚖️  
  Compare and understand **hard assertions** (immediate failure) vs. **soft assertions** (continue execution even after failure).

- **PriorityTest01.java** 📌  
  Demonstrates how to set priorities for test execution using `@Test(priority = n)`.

- **TestNGAnnotation01.java** 🏷️  
  A basic overview of essential TestNG annotations like `@BeforeTest`, `@AfterTest`, etc.

---

### ⚙️ **XML Configuration Files:**
- **GroupTest.xml** 👥  
  Runs tests grouped using `@Test(groups)` annotation.  

- **ListenersTestSuite.xml** 🔊  
  Demonstrates how to apply listeners at the XML level to monitor test execution.

- **ParallelClassesTestSuite.xml** 🏃‍♂️🏃‍♀️  
  Configures parallel execution for classes.

- **ParallelMethodsTestSuite.xml** 🧪🔄  
  Configures parallel execution for methods within a class.

- **ParallelSuitsTestSuite.xml** 🔄📦  
  Demonstrates parallel execution at the suite level.

- **ParameterTest.xml** 📊  
  Shows how to pass parameters to tests via XML configuration.

- **TestSuite.xml** 📁  
  A comprehensive suite file to run grouped tests.

- **testng.xml** 📝  
  The main configuration file for running TestNG tests.
